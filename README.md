# Manabu audio

Recorded Japanese speech for the Manabu JLPT app, voiced with Google Cloud Text-to-Speech (Chirp 3 HD).
GitHub Pages serves the files and the app downloads each one the first time it is needed.

- `s/` — lesson words and example sentences, generated by `server/tts-speech.mjs` in the app's repository.
- `l/` — listening (聴解) dialogs, generated by `server/tts-listening.mjs`.

File names are content hashes, so a changed text gets a new file. Do not edit or rename them by hand.
